# Relatório de Teste - Carregamento Dinâmico

## Informações do Teste
**ID do Caso de Teste:** TC-003  
**Título:** Teste de Carregamento Dinâmico  
**Site Alvo:** [https://the-internet.herokuapp.com/dynamic_loading/1](https://the-internet.herokuapp.com/dynamic_loading/1)  
**Data de Execução:** 30/04/2025  
**Executor:** Equipe de Testes Automatizados

## Objetivo
Verificar se ao clicar no botão **Start**, o sistema aguarda corretamente até o texto **"Hello World!"** estar visível e validar sua presença na página.

## Passos Executados
1. Inicializar o navegador Chrome
2. Navegar para a página "https://the-internet.herokuapp.com/dynamic_loading/1"
3. Localizar e clicar no botão "Start"
4. Aguardar o carregamento do texto "Hello World!" (timeout configurado: 30 segundos)
5. Verificar se o texto exibido é exatamente "Hello World!"
6. Fechar o navegador

## Resultado Esperado
O texto "Hello World!" deve aparecer após o carregamento dinâmico ser concluído.

## Resultado Obtido
* **Status:** Passou
* **Mensagem exibida:** "Hello World!"
* **Tempo de espera:** 5.32 segundos
* **Detalhes:** O elemento com o texto "Hello World!" foi localizado com sucesso após o período de carregamento dinâmico.

## Análise
O teste foi bem-sucedido, demonstrando que a funcionalidade de carregamento dinâmico está operando conforme o esperado. O WebDriver aguardou corretamente a visibilidade do elemento antes de verificar seu conteúdo.

### Pontos de Destaque:
1. **Uso de Explicit Waits:** Foi utilizado o `WebDriverWait` com `expected_conditions` para aguardar que o elemento se tornasse visível, evitando problemas de sincronização.
2. **Tratamento de Exceções:** O script inclui tratamento para `TimeoutException`, que seria acionado caso o elemento não aparecesse dentro do tempo limite definido.
3. **Registro de Tempo:** O tempo de espera foi registrado corretamente, permitindo análise de desempenho.
